# Contalink

> Contalink is a Mexican cloud accounting and payroll platform for independent accountants, accounting firms (despachos) and SMEs. It automates Mexican fiscal work — bulk CFDI download and classification, electronic accounting, DIOT, treasury and bank reconciliation, invoicing and payroll with digital stamping — and exposes a REST API to read and post accounting data.

## API

- [Contalink API reference](https://apidocs.contalink.com): REST API documentation (OpenAPI 3.0.0, v1.0.4)
- [API configuration guide](https://tutoriales.contalink.com/es/articles/8569647-configuracion-api): how to request and use your per-company API key

Authentication: static per-company API key sent in the `Authorization` header. Base URL: https://794lol2h95.execute-api.us-east-1.amazonaws.com/prod

Operations:
- GET /accounting/get-account-balance/{accountnumber}/ — account balance
- GET /accounting/trial-balance/ — trial balance (balanza de comprobación)
- POST/GET/PATCH/DELETE /accounting/manual-accounting-policy/ — manual accounting policies (pólizas manuales)
- POST /conciliation/create/ — invoice reconciliation (conciliación)
- GET /invoices/list/ — list CFDI fiscal documents
- POST /invoices/upload/ — upload a fiscal document XML (asynchronous)
- GET /invoices/check-status/{uuid}/ — CFDI status
- POST/GET/DELETE /treasury/bank-transactions/ — bank movements (movimientos bancarios)
